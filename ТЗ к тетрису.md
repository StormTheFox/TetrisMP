## Способ реализации:

### Глобальные переменные
```
ШИРИНА = 15
ВЫСОТА = 30
И1 = "игрок 1"
И2 = "игрок 2"
```

## Идеи
### Тетрис
Тетрис реализован как оригинальный тетрис, но с сеткой ШИРИНА на ВЫСОТА. Сложность выражается скоростью падения фигур, и каждые 25 линий это значение возрастает на 1/10 (0.1). Максимальное значение - 10. Игрок может выбрать следующие параметры:
* скорость падения фигур (0.1 - 10)
* цвет всех своих фигур (стандартный color picker)
* свой ник
* будет ли играть бот вместо игрока

### Режимы игры
**Игра всегда будет идти до поражения последнего игрока/команды - он(а) же бужет победителем**
* PvP
    * поля игроков разграничены 5 пикселями

* CO-OP
    * Ширина общего поля будер равна произведению `ШИРИНА` на количество игроков
    * Фигуры игроков *могут* входить друг в друга
    * Счёт только общий
    * Поле у игроков общее, и они могут входить на чужое поле

* 2PvP
    * Два поля, размеров `ШИРИНА * 2` на `ВЫСОТА`
    * две команды, по два игрока в каждой

### Тип игры
* Локальный (4 игрока)
    * Управление

|            | Игрок 1 | Игрок 2 | Игрок 3 | Игрок 4     |
|------------|---------|---------|---------|-------------|
|Hard Drop   | Q       | R       | U       | Right shift |
|Поворот (1) | W       | T       | I       | Up arrow    |
|Влево       | A       | F       | J       | Left arrow  |
|Вправо      | D       | H       | L       | Right arrow |
|Soft drop   | S       | G       | K       | Down arrow  |
|Hold        | E       | Y       | O       | Right CTRL  |
(1) - каждый игрок сможет выбрать, в какую сторону крутить фигуру. по дефолу - по часовой стрелке


* Сетевой (socketio)
    * Бинд устанавливается в настройках через отдельное окно tkinter
    * 6 кнопок:
        * HARD_DROP
        * ROTATE
        * LEFT
        * RIGHT
        * SOFT_DROP
        * HOLD
    * кнопка "Отмена" для отмены бинда

### Механики и внешний вид
* "Тень" от фигур
* Самый мощный алгоритм для самых быстрых игр и лучших результатов
* Размер клетки - 10px
* 100 очков за очищенную линию, 250 - за две, 500 - за три, 1000 - за четыре
* при зажатии кнопки, фигура выполнит команду, затем пройдёт задержка (200 мс), а затем действие будет циклично поаторяться (1 раз в 25 мс)
* Игроки смогут выбирать свой цвет:
    * при выборе цвета, **все** фигуры будут окрашены в выбраный цвет
* Кооп с ИИ должен быть реализован следующим образом:
    * ИИ делает ход основываясь на фигуре игрока И поле. Предполагая возможный ход игрока, бот должен подстраиваться под него. С учётом параметра "падающие фигуры неосязаемы", бот может подстраиваться ровно в фигуру игрока (что, по сути, есть жульничество, однако мне плевать, так надо)
* При выборе алгоритма можно будет выбрать самообучающийся алгоритм, который будет обучаться основываясь на действиях игрока
    * При запуске игры, скрипт запросит количество игровых циклов, во время которых алгоритм будет обучаться. После завершения N циклов скрипт сохранит JSON-параметры в файл для последующей загрузки модели
    * Если игра закроется при M < N (M - количество завершённых циклов, N - необходимых циклов), скрипт сохранит кэш модели (`имя модели.json.cache`), и при последующем запуске предложит либо продолжить обучение, либо сохранить текущую модель с M-ным количеством циклов
    * При обучении модели, игра всегда закрепит И1 как реального игрока, И2 - как бота-ученика. это нужно, чтобы отслеживать прогресс
* Если в режиме SocketIO игрок присоеденится к уже начатой игре, то:
    * PvP: он просто присоеденится и начнёт игру
    * CO-OP: он так же присоеденится, поле расширится, и всё поле зависнет на 5-10 секунд, чтобы все игроки могли понять, что произошло
    * 2PvP: так как здесь команды разбиты надвое, игрок перейдёт в режим зрителя с кнопкой "присоеденитьсч сейчас". При нажатии, он войдёт без союзника, и будет играть один, пока:
        * Один из врагов не покинет игру (тогда новый игрок присоеденится к старому)
        * Не присоеденится второй игрок (тогда двух новичков соединят в одну команду)
* В режиме SocketIO, в консоли (если stdout доступен, иначе создать отдельное окно для "чата") будет отображаться:
    * Сообщения других игроков
    * Сообщения системы (новый игрок, игрок покинул игру, соединение игрока А и Б в команду, ETC.)

### Внешний вид tkinter
* Четыре радиокнопки слева:
    * VS
    * COOP
    * 2VS2
    * Custom (Позволяет самостоятельно настроить команды, открывая возможности вроде 1vs3 или 1vs1vs2)
    * SocketIO (намертво блокирует И2-И4, позволяет настроить кнопки. При смене обратно, конфиги сбрасываются на дефолтные (таблица выше))
* 4 строки справа:
    * чекбокс (активен ли этот игрок)
    * поле ввода текста (отображаемый никнем)
    * кнопка окрашенная в цвет (цвет фигур этого игрока; кнопка должна окрашиваться в выбираемый цвет)
    * ползунок от 0.1 до 10.0 (скорость падения фигур этого игрока)
    * чекбокс (бот ли этот игрок)
* под ними - 4 кнопки:
    * начать игру
    * сохранить настройки (в json)
    * загрузить настройки
    * выйти

### Внешний вид pygame
* {количество игроков} полей
* над каждым полем отображается ник игрока, окрашенный в цвет его фигур
* под каждым полем есть два блока:
    * следующая фигура (слева)
    * удерживаемая фигура (справа)
    * соответствующие подписи расположены под этими блоками
* под блоками след.фигуры и удерж.фигуры (для VS) есть два текста:
    * Счёт
    * время (отсчитывает время в секундах до поражения)
* для COOP и 2VS2 эти параметры расположены в одну строку

## Реализация
### Меню Tkinter:
```python
import tkinter as tk
from tkinter import ttk, colorchooser, messagebox
from tkinter.font import Font

class TetrisSetup:
    def __init__(self):
        self.root = tk.Tk()
        self.root.title("Tetris Setup")
        self.root.geometry("600x500")
        self.root.resizable(False, False)
        self.root.configure(bg='#000')
        
        # Color scheme
        self.colors = {
            'bg': '#000',
            'frame_bg': '#000000',
            'accent': '#e94560',
            'text': '#eeeeee',
            'button': '#0f3460',
            'button_hover': '#533483'
        }
        
        # Player colors (default)
        self.player_colors = {
            1: '#FF4444',  # Red
            2: '#44FF44',  # Green
            3: '#4444FF',  # Blue
            4: '#FFFF44'   # Yellow
        }
        
        # Player enabled states
        self.player_enabled = {1: tk.BooleanVar(value=True), 
                               2: tk.BooleanVar(value=True),
                               3: tk.BooleanVar(value=True), 
                               4: tk.BooleanVar(value=True)}
        
        # Bot states
        self.player_is_bot = {1: tk.BooleanVar(value=False),
                              2: tk.BooleanVar(value=False),
                              3: tk.BooleanVar(value=False),
                              4: tk.BooleanVar(value=False)}
        
        # Falling speeds (1-10)
        self.fall_speeds = {}
        
        self.setup_ui()
        
    def setup_ui(self):
        # Main container
        self.main_container = tk.Frame(self.root, bg=self.colors['bg'])
        self.main_container.pack(fill='both', expand=True, padx=20, pady=20)
        
        # Title
        title_font = Font(family="Helvetica", size=24, weight="bold")
        title = tk.Label(self.main_container, text="TETRIS ⬛ SETUP", 
                        font=title_font, bg=self.colors['bg'], fg=self.colors['accent'])
        title.pack(pady=(0, 20))
        
        # Left and Right frames container
        top_container = tk.Frame(self.main_container, bg=self.colors['bg'])
        top_container.pack(fill='both', expand=True)
        
        # Left Frame - Game Mode
        self.create_game_mode_frame(top_container)
        
        # Right Frame - Players Configuration
        self.create_players_frame(top_container)
        
        # Bottom Frame - Controls
        self.create_controls_frame()
        
    def create_game_mode_frame(self, parent):
        left_frame = tk.LabelFrame(parent, text="Game Mode", 
                                  bg=self.colors['frame_bg'], fg=self.colors['text'],
                                  font=("Helvetica", 12, "bold"), padx=20, pady=15)
        left_frame.pack(side='left', fill='both', expand=True, padx=(0, 10))
        
        self.game_mode = tk.StringVar(value="vs")
        
        modes = [
            ("VS", "vs", "👥"),
            ("CO-OP", "coop", "🤝"),
            ("2 VS 2", "2vs2", "⚔️"),
            # Добавь SocketIO
        ]
        
        for i, (text, value, emoji) in enumerate(modes):
            rb = tk.Radiobutton(left_frame, text=f"{emoji} {text}", variable=self.game_mode, 
                               value=value, bg=self.colors['frame_bg'], fg=self.colors['text'],
                               selectcolor=self.colors['frame_bg'], font=("Helvetica", 11))
            rb.pack(anchor='w', pady=5)
            
    def create_players_frame(self, parent):
        right_frame = tk.LabelFrame(parent, text="Players Configuration", 
                                   bg=self.colors['frame_bg'], fg=self.colors['text'],
                                   font=("Helvetica", 12, "bold"), padx=15, pady=10)
        right_frame.pack(side='right', fill='both', expand=True, padx=(10, 0))
        
        # Headers
        headers = ["Player", "Enabled", "Color", "Speed", "Bot"]
        for col, header in enumerate(headers):
            label = tk.Label(right_frame, text=header, bg=self.colors['frame_bg'], 
                           fg=self.colors['accent'], font=("Helvetica", 10, "bold"))
            label.grid(row=0, column=col, padx=5, pady=5)
        
        self.color_buttons = {}
        self.speed_scales = {}
        self.enabled_checkboxes = {}
        self.bot_checkboxes = {}
        
        for player in range(1, 5):
            # Player label (Entry with smaller width - TODO completed)
            player_label = tk.Entry(right_frame, 
                                   bg=self.colors['frame_bg'], fg=self.colors['text'],
                                   font=("Helvetica", 10),
                                   width=10)  # Set width to 10 characters (was default ~20)
            player_label.insert(0, f"Player {player}")
            player_label.grid(row=player, column=0, padx=5, pady=5)
            
            # Enabled checkbox
            cb_enabled = tk.Checkbutton(
                                            right_frame, variable=self.player_enabled[player],
                                            bg=self.colors['frame_bg'],
                                            command=lambda p=player: self.toggle_player_controls(p)
                                       )
            cb_enabled.grid(row=player, column=1, padx=5, pady=5)
            self.enabled_checkboxes[player] = cb_enabled
            
            # Color button
            color_btn = tk.Button(right_frame, text="Choose", bg=self.player_colors[player],
                                 fg='white' if self.is_dark_color(self.player_colors[player]) else 'black',
                                 font=("Helvetica", 9), cursor="hand2",
                                 command=lambda p=player: self.choose_color(p))
            color_btn.grid(row=player, column=2, padx=5, pady=5)
            self.color_buttons[player] = color_btn
            
            # Speed scale
            speed_var = tk.DoubleVar(value=5.0)
            self.fall_speeds[player] = speed_var
            speed_scale = tk.Scale(right_frame, from_=1, to=10, orient='horizontal',
                                  variable=speed_var, bg=self.colors['frame_bg'],
                                  fg=self.colors['text'], length=100,
                                  command=lambda v, p=player: self.update_speed_label(p, v))
            speed_scale.grid(row=player, column=3, padx=5, pady=5)
            self.speed_scales[player] = speed_scale
            
            # Speed value label
            """speed_label = tk.Label(right_frame, text="5", width=3,
                                  bg=self.colors['frame_bg'], fg=self.colors['text'])
            speed_label.grid(row=player, column=4, padx=5, pady=5)
            speed_label.speed_value = 5
            speed_scale.speed_label = speed_label"""
            
            # Bot checkbox
            cb_bot = tk.Checkbutton(right_frame, variable=self.player_is_bot[player],
                                   bg=self.colors['frame_bg'])
            cb_bot.grid(row=player, column=4, padx=5, pady=5)
            self.bot_checkboxes[player] = cb_bot
        
        # Configure column weights
        for col in range(6):
            right_frame.columnconfigure(col, weight=1)
    
    def toggle_player_controls(self, player):
        """Enable/disable controls based on player enabled state"""
        state = 'normal' if self.player_enabled[player].get() else 'disabled'
        
        self.color_buttons[player].config(state=state)
        self.speed_scales[player].config(state=state)
        self.bot_checkboxes[player].config(state=state)
        
        # Also disable the speed label
        if hasattr(self.speed_scales[player], 'speed_label'):
            self.speed_scales[player].speed_label.config(state=state)
    
    def update_speed_label(self, player, value):
        """Update speed label when scale changes"""
        if hasattr(self.speed_scales[player], 'speed_label'):
            self.speed_scales[player].speed_label.config(text=str(int(float(value))))
    
    def choose_color(self, player):
        """Open color chooser dialog and update button color"""
        color = colorchooser.askcolor(title=f"Choose color for Player {player}",
                                      color=self.player_colors[player])
        if color[0]:  # If color was chosen
            hex_color = color[1]
            self.player_colors[player] = hex_color
            self.color_buttons[player].config(bg=hex_color,
                                             fg='white' if self.is_dark_color(hex_color) else 'black')
    
    def is_dark_color(self, hex_color):
        """Determine if a color is dark (for text contrast)"""
        hex_color = hex_color.lstrip('#')
        r, g, b = int(hex_color[0:2], 16), int(hex_color[2:4], 16), int(hex_color[4:6], 16)
        brightness = (r * 299 + g * 587 + b * 114) / 1000
        return brightness < 128
    
    def create_controls_frame(self):
        bottom_frame = tk.LabelFrame(self.main_container, text="Controls", 
                                    bg=self.colors['frame_bg'], fg=self.colors['text'],
                                    font=("Helvetica", 12, "bold"), padx=20, pady=15)
        bottom_frame.pack(fill='x', pady=(20, 0))
        
        # Buttons container
        buttons_container = tk.Frame(bottom_frame, bg=self.colors['frame_bg'])
        buttons_container.pack()
        
        # Style for buttons
        button_style = {
            'font': ("Helvetica", 11, "bold"),
            'cursor': "hand2",
            'padx': 20,
            'pady': 10,
            'relief': 'raised',
            'bd': 2
        }
        
        # Start Game Button
        start_btn = tk.Button(buttons_container, text="🚀 START GAME", 
                             bg=self.colors['button'], fg=self.colors['text'],
                             activebackground=self.colors['button_hover'],
                             activeforeground='white',
                             command=self.start_game, **button_style)
        start_btn.pack(side='left', padx=10)
        
        # Exit Button
        exit_btn = tk.Button(buttons_container, text="❌ EXIT", 
                            bg='#dc3545', fg='white',
                            activebackground='#c82333',
                            activeforeground='white',
                            command=self.exit_game, **button_style)
        exit_btn.pack(side='left', padx=10)
        
        # Hover effects
        for btn in [start_btn, exit_btn]:
            btn.bind("<Enter>", lambda e, b=btn: b.config(relief='sunken'))
            btn.bind("<Leave>", lambda e, b=btn: b.config(relief='raised'))
        
        # Info label
        info_text = "Configure your game settings and click START GAME to begin!"
        info_label = tk.Label(bottom_frame, text=info_text, 
                             bg=self.colors['frame_bg'], fg=self.colors['text'],
                             font=("Helvetica", 9, "italic"))
        info_label.pack(pady=(10, 0))
    
    def start_game(self):
        """Gather all settings and start the game"""
        # Check if at least one player is enabled
        enabled_players = [p for p in range(1, 5) if self.player_enabled[p].get()]
        
        if not enabled_players:
            messagebox.showwarning("No Players", "Please enable at least one player to start the game!")
            return
        
        # Prepare settings summary
        settings = {
            'game_mode': self.game_mode.get(),
            'players': {}
        }
        
        mode_names = {'vs': 'VS Mode', 'coop': 'CO-OP Mode', '2vs2': '2 VS 2 Mode'}
        
        summary = f"🎮 Game Settings:\n"
        summary += f"Mode: {mode_names[settings['game_mode']]}\n\n"
        summary += "👤 Players:\n"
        
        for player in range(1, 5):
            if self.player_enabled[player].get():
                is_bot = "🤖 Bot" if self.player_is_bot[player].get() else "👤 Human"
                speed = int(self.fall_speeds[player].get())
                color = self.player_colors[player]
                settings['players'][player] = {
                    'enabled': True,
                    'is_bot': self.player_is_bot[player].get(),
                    'speed': speed,
                    'color': color
                }
                summary += f"  Player {player}: {is_bot}, Speed: {speed}, Color: {color}\n"
        
        summary += f"\nClick OK to start the game with these settings!"
        
        if messagebox.askokcancel("Game Configuration", summary):
            # Here you would initialize and start your actual Tetris game
            messagebox.showinfo("Starting Game", "Game is starting! (Game logic would go here)")
            # self.root.destroy()  # Uncomment if you want to close setup when game starts
            # Launch your Tetris game here
    
    def exit_game(self):
        """Exit the application"""
        if messagebox.askyesno("Exit", "Are you sure you want to exit?"):
            self.root.destroy()
    
    def run(self):
        self.root.mainloop()

if __name__ == "__main__":
    app = TetrisSetup()
    app.run()
```
